# Reseller Earnings Calculator

A one-page calculator for Local Knowledge's white-label reseller program. An agency enters its number of clients, average locations per client, the wholesale price and its own resale price, and sees its monthly and yearly margin, what it bills clients, margin per client and Local Knowledge's revenue.

**Live page:** https://shorouk9.github.io/lk-reseller-partner-kit/

Prices are examples ($10 wholesale, $25 suggested resale per location per month), not real pricing. Nothing entered leaves the browser.

A single self-contained `index.html`, hosted on GitHub Pages.
