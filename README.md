# Reseller Earnings Calculator

A one-page calculator for Local Knowledge's white-label reseller program.

**Inputs:** clients, average locations per client, wholesale and resale price per location, setup fee charged and paid, volume discount (threshold and %), team time per location and hourly cost, new clients per month and monthly client loss.

**Outputs:** profit per month after team cost, margin, team cost, client billing, first-month setup fees, profit per client, Local Knowledge's revenue, how each client dollar splits, and a 12-month profit projection.

**Live page:** https://shorouk9.github.io/lk-reseller-partner-kit/

All defaults are examples ($10 wholesale, $25 resale, $50 setup fee, 10% off above 250 locations, 15 min at $20/hour per location), not real pricing. Nothing entered leaves the browser.

A single self-contained `index.html`, hosted on GitHub Pages.
