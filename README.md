# Reseller Earnings Calculator

A one-page calculator for Local Knowledge's white-label reseller program.

**Inputs:** clients, average locations per client, wholesale and resale price per location, setup fee charged and paid, new clients per month and monthly client loss.

**Outputs:** margin per month, client billing, first-month setup fees, margin per client, Local Knowledge's revenue, how each client dollar splits, and a 12-month projection.

**Live page:** https://shorouk9.github.io/lk-reseller-partner-kit/

All defaults are examples ($10 wholesale, $25 resale, $50 setup fee), not real pricing. Nothing entered leaves the browser.

A single self-contained `index.html`, hosted on GitHub Pages.
